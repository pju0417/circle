# 원을 잘라 직사각형 만들기

초등 6학년 수학 6-2 5단원 「원의 둘레와 넓이」 중 **원의 넓이를 구하는 방법**(교과서 108~109쪽)을 탐구하는 단일 HTML 도구입니다.

- 원을 8·16·32·64·128등분(2~200 짝수)하여 이어 붙이고, 마지막 조각을 반으로 잘라 직사각형을 만드는 애니메이션
- 반지름·원주율(3 / 3.1 / 3.14 / 정확한 값) 변경, 식으로 단계별 정리
- 원 안·밖 정사각형으로 넓이 어림하기, 빈칸 채우기·계산 문제, 그림 PNG 저장

## 배포 (GitHub Pages)
1. 이 브랜치를 `main`에 병합합니다.
2. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch**, Branch: `main` / `(root)` 선택 후 Save.
3. 잠시 후 `https://pju0417.github.io/circle/` 로 접속할 수 있습니다.

외부 라이브러리 없이 `index.html` 하나로 동작합니다.
