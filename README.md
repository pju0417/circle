# 원을 잘라 직사각형 만들기

초등 6학년 수학 6-2 5단원 「원의 둘레와 넓이」 중 **원의 넓이를 구하는 방법**(교과서 108~109쪽)을 탐구하는 단일 HTML 도구입니다.

- 원을 4~200등분(짝수)하여, 위쪽 반원 조각을 먼저 늘어놓고 아래쪽 반원 조각을 사이에 끼워 이어 붙이는 애니메이션
- 34등분 이상에서는 조각이 붙는 자리를 확대해서 보여 주고, 다 붙으면 축소해서 전체와 처음의 원을 보여 줌
- 등분한 조각 한 개를 확대해서 보여 주어, 등분 수가 많을수록 호가 직선에 가까워짐을 확인
- 그림 PNG 저장

## 배포 (GitHub Pages)
1. 저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch** 를 선택합니다.
2. Branch를 `claude/great-cray-w82ppm` / `(root)` 로 지정하고 Save 합니다.
3. 잠시 후 `https://pju0417.github.io/circle/` 로 접속할 수 있습니다.

외부 라이브러리 없이 `index.html` 하나로 동작합니다.
